Descripción del proyecto

AlzMemory es un sistema web desarrollado para apoyar a personas que padecen Alzheimer y a sus cuidadores. La plataforma ofrece ejercicios cognitivos interactivos, recordatorios personalizados y un panel de seguimiento del progreso del paciente.

El proyecto nació como una propuesta de valor social durante la carrera, con el objetivo de aplicar tecnología web para mejorar la calidad de vida de adultos mayores con deterioro cognitivo.

Características principales
Ejercicios de memoria interactivos adaptados al nivel del paciente
Sistema de recordatorios de medicamentos y actividades diarias
Panel de seguimiento del progreso para cuidadores
Interfaz accesible y sencilla para adultos mayores
Gestión de múltiples pacientes desde un solo panel
Autenticación de usuarios con roles (cuidador / paciente)
Resultados obtenidos
Proyecto presentado y aprobado ante comité académico con calificación sobresaliente.
Interfaz validada con usuarios adultos mayores, logrando navegación autónoma.
Base de datos optimizada para consultas rápidas de historial de actividades.
